# Primitive DB

Это учебный проект простой базы данных на Python.

Программа позволяет создавать таблицы, просматривать список существующих таблиц и удалять их. Информация о структуре таблиц сохраняется в JSON-файле, поэтому метаданные не теряются после завершения программы.

## Запуск проекта

Проект использует `uv` для управления окружением и зависимостями.

Для установки зависимостей выполните:

`uv sync`

После этого запустите базу данных:

`uv run project`

## Управление таблицами

После запуска программа ожидает ввода команд.

### Создание таблицы

Для создания таблицы используется команда:

`create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...`

Например:

`create_table users name:str age:int is_active:bool`

Программа автоматически добавляет столбец `ID:int` в начало таблицы, если пользователь его не указал.

Поддерживаются три типа данных: `int`, `str`, `bool`.

Пример результата:

`Таблица "users" успешно создана: со столбцами: ID:int, name:str, age:int, is_active:bool`

### Просмотр таблиц

Чтобы посмотреть список созданных таблиц, используется команда:

`list_tables`

Пример результата:

- users

### Удаление таблицы

Для удаления таблицы используется команда:

`drop_table <имя_таблицы>`

Например:

`drop_table users`

Пример результата:

`Таблица "users" успешно удалена`

### Справка

Команда `help` выводит список доступных команд.

### Выход из программы

Команда `exit` завершает работу приложения.

## Хранение метаданных

Структура таблиц хранится в файле `db_meta.json`.

В нём сохраняются имена таблиц и список их столбцов с типами данных.

Если файл ещё не существует, программа начинает работу с пустым словарём метаданных. При первом успешном создании таблицы метаданные сохраняются в JSON-файл.

На данном этапе приложение хранит только структуру таблиц, а не записи внутри них.

## Пример работы

Запуск приложения:

`uv run project`

**Процесс работы с таблицей**

Функции:

- `create_table <имя_таблицы> <столбец1:тип> ...` — создать таблицу
- `list_tables` — показать список всех таблиц
- `drop_table <имя_таблицы>` — удалить таблицу
- `exit` — выйти из программы
- `help` — справочная информация

**Пример консольной сессии**

**Команда:** `create_table a name:str age:int is_active:bool`

Таблица "a" успешно создана: со столбцами: ID:int, name:str, age:int, is_active:bool

**Команда:** `list_tables`

- a

**Команда:** `create_table products price:float`

Ошибка: float неверный тип данных

**Команда:** `create_table products price`

Некорректное значение: price. Попробуйте снова.

**Команда:** `drop_table d`

Ошибка: Таблица "d" не существует

**Команда:** `drop_table a`

Таблица "a" успешно удалена

**Команда:** `list_tables`

Таблиц не существует

**Команда:** `list_tables dfgd`

Некорректное значение: dfgd. Попробуйте снова.

**Команда:** `exit`
